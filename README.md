# 🟢 Matrix-themed Portfolio

Built with **React**, **Vite**, **TypeScript**, and a healthy dose of `pnpm`.

---

> **I hadn’t touched frontend in a while**, so this was my way to refresh some of my skills.  
> ChatGPT helped me vibe-code my way through CSS quirks and smooth animations 😄

---

## 🧠 What’s inside?

- React + Vite + TypeScript setup with blazing-fast builds ⚡  
- Matrix UI vibes with `monospace` font & green-on-black palette 💻  
- Custom Matrix rain effect via canvas (reused code from [this repo](https://github.com/FullStackWithLawrence/react-mdr/tree/main)) 🌧️  
- Animated transitions, focus-based section opacity, and glitchy name header ✨  
- CI/CD via GitHub Actions + GitHub Pages deployment 📦
